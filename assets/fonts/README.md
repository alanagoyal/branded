# PDF fonts

Noto Sans Regular and Bold are bundled for offline PDF rendering, including accented Latin text, Greek, Cyrillic, and common Unicode punctuation. Other scripts may require additional fonts.

Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), retrieved September 21, 2026. Files are unmodified and distributed under the included SIL Open Font License (`OFL.txt`).
