# Support

Support goes through [GitHub issues](https://github.com/alanagoyal/branded/issues).
The help page is available without signing into Branded. Creating an issue requires
a GitHub account; visitors submit their own report on GitHub.

The help page explains that issues are public and asks visitors to leave out
credentials, payment details, and personal information. Account deletion remains
available from Account, with instructions on the help page.

There is no support chatbot, email form, or support-provider API request. Pricing
and billing/account error links use the same GitHub support path for every plan.
No support credentials are required. After deployment, the retired
`NEXT_PUBLIC_PROJECT_KEY` and optional `NEXT_PUBLIC_API_URL` variables can be removed
from hosting configuration.
